# Unidad-2-Ejercicio-5
Programacion 3 Unidad 2 Ejercicio 5
Ejercicio 5 — Mi primer evento: botón que responde
Este ejercicio marca el inicio del trabajo con eventos. El objetivo es que implementes tu primer ActionListener y veas cómo la interfaz puede reaccionar a las acciones del usuario.

Creá una ventana con los siguientes componentes:

Una etiqueta con el texto "Presioná el botón para comenzar"
Un botón con el texto "Saludar"
Cuando el usuario presione el botón "Saludar", la etiqueta debe cambiar su texto a "¡Hola! Bienvenido a Swing."

Implementá el ActionListener de dos formas distintas y dejá ambas versiones comentadas en el código:

Usando una clase anónima
Usando una expresión lambda
En un comentario al final del código, escribí con tus palabras cuál de las dos formas te resulta más clara y por qué.

💡 Tip: para cambiar el texto de una etiqueta en tiempo de ejecución usá el método setText("nuevo texto") sobre el objeto JLabel.
